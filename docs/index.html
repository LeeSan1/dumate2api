使用前必读

  • 必须登录并保持 DuMate 桌面客户端运行。关闭客户端、退出登录或结束后台进程后，代理会返回 503 dumate_unavailable。
  • 使用当前账户原有的额度和会员权限。本项目不提供新的免费额度，不绕过登录、会员限制或风控，也不包含账号池、自动切换账户或自动签到。
  • Windows 需要手动配置本机后端信息。当前自动发现逻辑依赖 macOS/Linux 的 ps；Windows 请设置 DUMATE_BACKEND_PORT 和 DUMATE_INAPP_KEY。临时密钥通常会在 DuMate 重启后变化。
  • 默认只供本机使用。代理只监听 127.0.0.1，其他电脑和手机不能直接访问，也不能把它当作公网 API。
  • 注意默认端口冲突，/healthz 不是 DuMate 就绪检查。3066 可能已被 Magpie 或 Codex Router 占用；当 /healthz 没有返回指定 JSON 时，改用 3067，并同步修改客户端 Base URL。即使返回正常，也只表示反代自身在线，不代表 DuMate 已登录或有可用额度。
  • 这是非官方、依赖内部接口的本机桥接。客户端升级或改版后，qianfanproxy 路径、进程名或动态密钥可能变化。当前验证的是 Chat Completions（含流式）；Images、Audio、Embeddings 等未承诺兼容，也不等同于官方 DuMate Agent API。
  • 客户端里的 API Key 只是占位值。填 local-test 等任意非空值即可。不要保存、提交或公开真实的 DUMATE_INAPP_KEY。
  • 当前只公开四个模型别名，/v1/models 不会探测账户权限。模型是否可用仍取决于 DuMate 版本和账户权限，客户端升级后列表也可能变化。

项目概览

百度搭子 DuMate 桌面端内置了可供本机调用的千帆代理接口，但它不是一个可直接交给通用客户端使用的公开 API。这个项目负责在 127.0.0.1 上把它整理成标准的 OpenAI Chat Completions 入口。

Client OpenAI SDK OpenClaw / Magpie / 脚本
→
Local bridge 百度搭子 DuMate 反代 路径、模型与鉴权转换
→
Desktop DuMate qianfanproxy + 登录态

代理会通过 ps 发现本机运行的 dumate-main-server 子进程，读取它的动态端口与临时密钥。密钥不会落盘，也不会写进日志；客户端填写的 API Key 只是占位值。

准备工作

1. 安装 DuMate 并登录

桌面端必须保持运行，且当前账户已经登录。关闭客户端后，本机兼容接口也会随之不可用。

2. 安装 Node.js 18+

macOS 可执行 brew install node，Windows 可从 Node.js 官网安装 LTS 版本。

项目自身没有 npm 依赖，因此克隆后无需运行 npm install。macOS 和 Linux 通常可以自动发现 DuMate；Windows 原生运行需要显式提供后端端口和临时密钥。

快速开始

克隆项目把仓库下载到一个本地目录。
先启动 DuMate完成登录，确认客户端可以正常使用。
启动代理默认使用 3066；若已被占用，改用 3067。
验证模型访问 /healthz 与 /v1/models。
bash
git clone https://github.com/LeeSan1/dumate2api.git
cd dumate2api

# 默认端口 3066
./run.sh

# 如果端口已被其他服务占用
./run.sh --port 3067
macOS：也可以双击 start.command。Windows 使用 npm start 或 run.bat。

接口验证

先检查服务是否由本项目响应。若 /healthz 返回的不是下面这段 JSON，说明端口被其他程序占用了，应换一个端口重启代理。

bash
curl http://127.0.0.1:3067/healthz
curl http://127.0.0.1:3067/v1/models
expected JSON
{"ok":true,"service":"dumate-openai-proxy"}

客户端接入

所有客户端都使用同一组参数：Base URL 指向本机代理，API Key 填任意占位值，模型选择下面四个 dumate-* 别名之一。

cURL

bash
curl http://127.0.0.1:3067/v1/chat/completions \
  -H 'content-type: application/json' \
  -H 'authorization: Bearer local-test' \
  -d '{
    "model": "dumate-deepseek-v41-flash",
    "messages": [{"role": "user", "content": "只回复 OK"}]
  }'

OpenAI SDK

javascript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://127.0.0.1:3067/v1",
  apiKey: "local-test",
});

const response = await client.chat.completions.create({
  model: "dumate-deepseek-v41-flash",
  messages: [{ role: "user", content: "只回复 OK" }],
});

console.log(response.choices[0].message.content);

OpenClaw / Magpie

json
{
  "baseUrl": "http://127.0.0.1:3067/v1",
  "apiKey": "local-test",
  "models": [
    { "id": "dumate-deepseek-v41-flash" },
    { "id": "dumate-deepseek-v4-pro" },
    { "id": "dumate-deepseek-v4-flash-0731" },
    { "id": "dumate-glm-5" }
  ]
}

若 Magpie 或 Codex Router 已经在 3066 提供聚合入口，请直接沿用原来的 Base URL，并在模型列表中启用 dumate-* 模型；不要再启动一个监听同端口的实例。

配置项

.env
DUMATE_PROXY_HOST=127.0.0.1
DUMATE_PROXY_PORT=3067
DUMATE_UPSTREAM_PREFIX=/api/qianfanproxy/v1

# 自动发现失败时才显式填写；临时密钥不要提交到 Git
# DUMATE_BACKEND_PORT=12345
# DUMATE_INAPP_KEY=do-not-commit-this-value

可用参数还包括 --route-bare-models、--allow-unknown-models、--process-name 和 --max-body-bytes。运行 ./run.sh --help 可查看完整说明。

常见问题

访问 /healthz 却返回其他服务的 JSON 或 404

默认端口被占用了。本项目默认使用 3066，它可能同时被 Magpie 或 Codex Router 使用。看到 service 不是 dumate-openai-proxy 时，执行 ./run.sh --port 3067，并把客户端 Base URL 改成 3067。

503 · dumate_unavailable

DuMate 没有运行、尚未登录，或当前版本不再暴露预期的本机进程。先重启并登录客户端；仍失败时使用环境变量显式提供本机后端端口和临时密钥。

400 · unsupported_model

模型名不在默认前缀范围内，或不是已知别名。先使用 /v1/models 返回的四个名称。确实需要裸模型名时，可设置 DUMATE_ROUTE_BARE_MODELS=1。

Windows 上无法自动发现 DuMate

当前自动发现依赖 macOS/Linux 的 ps。Windows 请在本机设置 DUMATE_BACKEND_PORT 和 DUMATE_INAPP_KEY 后再启动代理；DuMate 重启后如密钥变化，需要同步更新。不要把真实值写入仓库。

能关闭 DuMate 桌面端吗

不能。本机代理依赖桌面端提供的 qianfanproxy，关闭客户端后服务会不可用。当前版本也只使用客户端已登录的那一个账户。

安全边界

不要把代理直接暴露到公网。默认绑定 127.0.0.1，这既是安全边界，也是项目当前的使用前提。远程访问需要额外增加认证、TLS、限流和访问控制。
  • 代理不包含 DuMate 账户密钥，也不绕过登录、会员权限或风控。
  • 客户端传入的 Authorization 会被替换为本地服务所需的鉴权头。
  • 动态密钥只留在内存中，不写入文件，也不输出到日志。
  • 桌面客户端必须保持运行，关闭后代理不可用。
  • 本项目只桥接当前登录账户，不提供账号池或自动签到。

FAQ

它和官方 DuMate Agent API 是一回事吗？

不是。官方 API 使用 Enterprise API Key，并采用 Agent、Session 与 SSE 事件流；本项目桥接的是本机已登录桌面端里的 OpenAI 兼容路由，只适合当前登录用户的本地调用。

支持流式输出吗？

支持。代理保留请求方式和响应头，并把上游字节流直接回传给客户端；在 OpenAI SDK 里设置 stream: true 即可。

如何更换端口并让客户端生效？

服务端和客户端必须使用同一个端口。例如本地运行 ./run.sh --port 3067，客户端 Base URL 就应填写 http://127.0.0.1:3067/v1。
